---
title: "第3章 型同士の関係と型方程式"
---

第2章では、型なし定数を考えなくてよい単純な型推論と、より一般的な型推論の全体像を見ました。

この章からは、[仕様書のType inference節](https://go.dev/ref/spec#Type_inference)を上から順番に読みます。

この章が扱うのは、Type inference節の冒頭4段落です。

1. 型引数を省略できることと、型推論の成功条件
2. 型推論が型同士の関係を利用すること
3. 型引数と型制約の関係も利用すること
4. それらの関係が型方程式になり、型引数の推論は型方程式の集合を解くことだという説明

具体的な記法、型方程式を作る詳しい規則、型方程式を解く手続きは、この後の仕様書に現れる順番で扱います。

## 型引数を省略する

ジェネリック関数を使うとき、使われている文脈から型引数を推論できるなら、一部または全部の型引数を省略できます。

<!-- zenncode: skip -->
```go
func G[T any](t T) {}

var x int
G(x)
```

`G`には型パラメータ`T`があります。本来は、次のように型引数を明示できます。

<!-- zenncode: skip -->
```go
G[int](x)
```

しかし`G(x)`では、型引数`int`が省略されています。型推論は、この省略された型引数を関数が使われている文脈から求めます。

この例で使える主な情報は次の2つです。

- 実引数`x`の型が`int`である
- 型パラメータ`T`の型制約が`any`である

## 型推論の成功条件

型推論が成功するには、単に型引数の候補を見つけるだけでは足りません。

1. 省略された型引数をすべて推論できる
2. 推論された型引数を使ったインスタンス化に成功する

この2つが必要です。

`G(x)`では、`T`の型引数として`int`を推論できます。また、`int`は`T`の型制約`any`を満たすため、`G[int]`のインスタンス化にも成功します。

どこかの段階で失敗すれば、型推論は失敗し、そのプログラムは不正になります。

## 型の対の間にある関係

型推論は、2つの型の間に必要な関係を利用します。

`G(x)`では、実引数`x`を仮引数`t`へ渡します。

| 対象 | 型 |
| --- | --- |
| 実引数`x` | `int` |
| 仮引数`t` | `T` |

関数呼び出しが有効であるためには、実引数`x`を仮引数`t`へ渡せなければなりません。したがって、実引数の型`int`と仮引数の型`T`の間に、代入可能性にもとづく関係が必要です。

型推論は、この関係が成立するような`T`の型引数を探します。この例では、`T`を`int`に置き換えれば、実引数と仮引数の型の関係を成立させられます。

```text
T ➞ int
```

ここで重要なのは、型推論が型を1つずつ孤立して調べるのではなく、使用箇所で対応する2つの型を対にしていることです。

## 型引数と型制約の関係

型推論が利用するのは、実引数と仮引数の関係だけではありません。

型パラメータには型制約があり、推論された型引数はその型制約を満たす必要があります。`G`の型パラメータ宣言をもう一度見ます。

<!-- zenncode: skip -->
```go
func G[T any](t T) {}
```

ここでは、型パラメータ`T`と型制約`any`の間に「`T`の型引数は`any`を満たす」という関係があります。

`T`の型引数として得られた`int`は`any`を満たします。このため、実引数と仮引数から得られた情報と、型パラメータと型制約から得られた情報は両立します。

型制約によっては、候補が制約を満たさず、インスタンス化に失敗することもあります。また、型制約の中に別の型パラメータが現れ、その型引数を推論する手がかりになることもあります。後者は次章の`dedup`の例で扱います。

## 型同士の関係を型方程式にする

仕様書では、型推論に使う型の対を型方程式として表します。

`G(x)`から得られる関係を、後続の仕様書で導入される記法を使って先に書くと、次のようになります。

```text
T ≡A int
T ≡C any
```

1つ目は、仮引数の型`T`と実引数の型`int`の間に必要な関係を表します。2つ目は、型パラメータ`T`と型制約`any`の間に必要な関係を表します。

この時点では、`≡A`と`≡C`を次のように捉えてください。

| 記号 | この例で表していること |
| --- | --- |
| `≡A` | 実引数を仮引数へ渡せるように、2つの型が対応する |
| `≡C` | 型パラメータの型引数が、対応する型制約を満たす |

記号の左右に置けるもの、対称性、型方程式の生成規則は、仕様書でそれぞれ説明される箇所まで進んでから詳しく確認します。

## 型方程式の集合を解く

型推論では、1つの型方程式だけを見るとは限りません。1つまたは複数のジェネリック関数から、1個以上の型パラメータを含む複数の型方程式が得られることがあります。

省略された型引数を推論するとは、得られた型方程式の集合をすべて成立させる型引数を求めることです。

`G(x)`の場合は、次の2つを両方成立させる必要があります。

```text
T ≡A int
T ≡C any
```

`T ➞ int`とすれば、実引数と仮引数の関係が成立し、`int`は`any`も満たします。その型引数で`G[int]`をインスタンス化できるため、型推論は成功します。

この例は、型パラメータが1つだけの単純なものです。次章では仕様書が続けて示す`dedup`の例を読み、2つの型方程式から`S`と`E`の型引数が得られる過程を確認します。
