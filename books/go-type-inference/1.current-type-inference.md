---
title: "第1章 現在のGoでできる型推論"
---

Goのジェネリック関数やジェネリックメソッドを使うとき、型引数の一部または全部を省略できることがあります。
省略された型引数を、関数が使われている文脈から決める処理が型推論です。

この章では、細かい仕組みを読む前に、現在のGoでどのような型推論ができるのかをサンプルコードで見ていきます。
型方程式やunificationなどの用語は次の章から順番に説明するので、ここではまだ知らなくて構いません。

**最終更新時のGoバージョン: Go 1.27**

## まず最小の例を見る

次のジェネリック関数`G`は、型パラメータ`T`と、型`T`の仮引数`t`を持ちます。

<!-- zenncode: skip -->
```go
func G[T any](t T) {
	fmt.Printf("%T\n", t)
}
```

型引数を明示して呼び出す場合は、`G[int](x)`と書けます。
しかし、`x`の型が`int`であるなら、次のように型引数を省略できます。

<!-- zenncode: skip -->
```go
var x int
G(x)
```

コンパイラは、実引数`x`の型から`T`の型引数を`int`と推論します。
これはGoの型推論の最も基本的な例です。

## 現在使える型推論のパターン

現在のGoでは、通常の関数呼び出し以外でも型引数を推論できます。
主なパターンを一つのプログラムにまとめると次のようになります。

<!-- zenncode: expect=run output=next -->
```go
package main

import "fmt"

func G[T any](t T) {
	fmt.Printf("%T\n", t)
}

func acceptInt(f func(int)) {
	f(2)
}

func returnIntFunction() func(int) {
	return G // 戻り値の型 func(int) に G が代入可能になるよう、T を int と推論する
}

func pair[A, B any](a A, b B) {
	fmt.Printf("%T, %T\n", a, b)
}

func first[S ~[]E, E any](s S) E {
	return s[0]
}

type Printer struct{}

// Go 1.27では、メソッド自身も型パラメータを宣言できる。
func (Printer) G[T any](t T) {
	fmt.Printf("%T\n", t)
}

func main() {
	var x int

	// 1. 通常の関数呼び出し
	G(x) // xが仮引数Tに代入可能になるよう、Tをintと推論する

	// 2. 既知の関数型の変数への代入
	var assigned func(int) = G // G[T]がfunc(int)になるよう、Tをintと推論する
	assigned(1)

	// 3. 別の関数へ引数として渡す
	acceptInt(G) // G[T]が仮引数型func(int)になるよう、Tをintと推論する

	// 4. 戻り値として返す
	returned := returnIntFunction()
	returned(3)

	// 5. 既知の関数型への変換（Go 1.27）
	converted := (func(int))(G) // G[T]がfunc(int)になるよう、Tをintと推論する
	converted(4)

	// 6. ジェネリックメソッドの呼び出し（Go 1.27）
	Printer{}.G(x) // xが仮引数Tに代入可能になるよう、Tをintと推論する

	// 7. 型引数を一部だけ明示する
	pair[int](x, "hello") // Aは明示したint、残るBはstringと推論する

	// 8. 制約から別の型引数を推論する
	e := first([]string{"hello"}) // 実引数からSは[]string、制約S ~[]EからEはstring
	fmt.Printf("%T\n", e)
}
```

## 通常の関数呼び出し

<!-- zenncode: skip -->
```go
G(x)
```

実引数`x`の型は`int`で、対応する仮引数`t`の型は`T`です。
そのため、`x`を`t`へ渡せるように、`T`の型引数が`int`と推論されます。

これは、型引数を明示した`G[int](x)`と同じ関数を呼び出します。

## 既知の関数型の変数への代入

<!-- zenncode: skip -->
```go
var assigned func(int) = G
```

左辺の変数`assigned`の型は`func(int)`と決まっています。
そこで、右辺の`G`がこの関数型へ代入できるように、`T`の型引数が`int`と推論されます。

この例では、関数を呼び出すときの実引数ではなく、代入先の型が型推論の手がかりになっています。

## 別の関数の引数として渡す

<!-- zenncode: skip -->
```go
acceptInt(G)
```

`acceptInt`の仮引数`f`の型は`func(int)`です。
実引数として渡す`G`がこの型に合うように、`T`の型引数が`int`と推論されます。

関数の引数を渡す処理も代入の一種なので、直前の変数への代入とよく似た型推論が行われます。

## 関数の戻り値として返す

<!-- zenncode: skip -->
```go
func returnIntFunction() func(int) {
	return G
}
```

関数`returnIntFunction`の戻り値の型は`func(int)`です。
`return G`の`G`がこの戻り値の型に合うように、`T`の型引数が`int`と推論されます。

ここでも型推論の手がかりは、`G`を呼び出す実引数ではなく、`G`が置かれた場所に要求される関数型です。

## 関数型への変換

<!-- zenncode: skip -->
```go
converted := (func(int))(G)
```

このコードでは、ジェネリック関数`G`を`func(int)`へ変換しています。
変換先の関数型に合うように、`T`の型引数が`int`と推論されます。

ジェネリック関数に対して、このようなすべての代入の文脈で型推論が使えるようになったのはGo 1.27からです。

## ジェネリックメソッド

<!-- zenncode: skip -->
```go
type Printer struct{}

func (Printer) G[T any](t T) {
	fmt.Printf("%T\n", t)
}

var x int
Printer{}.G(x)
```

Go 1.27では、メソッド自身も型パラメータを宣言できるようになりました。
ジェネリックメソッドを呼び出す場合も、通常のジェネリック関数と同じように、実引数`x`から`T`の型引数が`int`と推論されます。

## 型引数を一部だけ明示する

<!-- zenncode: skip -->
```go
pair[int](x, "hello")
```

関数`pair`は、`A`と`B`という二つの型パラメータを持ちます。
この呼び出しでは先頭の型引数`A`だけを`int`と明示し、残りの`B`を省略しています。

第2実引数`"hello"`から、`B`の型引数は`string`と推論されます。
型引数を一部だけ明示する場合、明示する型引数は型パラメータの並びの先頭から指定します。

## 制約から別の型引数を推論する

<!-- zenncode: skip -->
```go
func first[S ~[]E, E any](s S) E {
	return s[0]
}

e := first([]string{"hello"})
```

この例では、まず実引数`[]string{"hello"}`から`S`の型引数が`[]string`と推論されます。

`S`には`~[]E`という型制約があります。これは、`S`のunderlying typeが`[]E`でなければならないという制約です。
`S`が`[]string`だと分かったので、この制約からさらに`E`の型引数が`string`と推論されます。

このように、実引数から直接決まらない型引数が、別の型パラメータの制約を通して決まることもあります。

## 型推論が行われないもの

ここまで見てきた型推論の対象は、ジェネリック関数とジェネリックメソッドです。
ジェネリック型を使う場合は、型引数を省略できません。

たとえば`type Box[T any] struct { value T }`という型がある場合は、`Box[int]`のようにすべての型引数を明示する必要があります。

また、ジェネリック関数を型の手がかりがない場所で単独で使うこともできません。
たとえば`x := G`では、`T`を決める情報がないため型推論に失敗します。

## この章のまとめ

- 通常の関数呼び出しでは、実引数の型から型引数を推論できる
- ジェネリック関数に要求される関数型からも型引数を推論できる
- 型引数の一部だけを明示し、残りを推論させることができる
- 一つの型パラメータについて得た情報を、型制約を通して別の型パラメータの推論に使える
- Go 1.27では、関数型への変換とジェネリックメソッドでも型推論を利用できる
- ジェネリック型の型引数は省略できない

次の章では、これらの型推論がどのような手順で行われるのか、全体像を見ていきます。
